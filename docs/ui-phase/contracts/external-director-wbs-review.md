# Screen Contract: External → Director WBS Review (Token Link)

**Status:** Draft for Lapedra review, 2026-07-13
**Section:** External (no login, token-scoped)
**Gate complexity:** None — read-only; per PRINCIPLES §8, the product's argument to a skeptic

---

## Purpose

A director opens a link to answer one question: *are the right people on the right work, in defensible amounts?* She gets structure, staffing, hours, and grounding — not a login, not a spreadsheet export, not the whole product. Zero learning curve is a requirement: the page must explain itself.

## Access model

Token resolves to a specific frozen target. For M1, the director view reads from a **generated artifact's WBS/staffing sections** (or a snapshot's), never live tables — consistent with the 6B share-link re-pointing. If the current token implementation still permits live-WBS reads, that's a legacy-deprecated path per the snapshot/share contract; new director links target artifacts.

## Reads (exhaustive)

| Data | Source | Rule |
|---|---|---|
| Provenance header | artifact metadata | What this is, generated when, from which confirmed intelligence (hash), artifact content hash. First thing on the page, plain language |
| Task structure | artifact content: wbs_estimates section | Hierarchy, wbs codes, task titles |
| Staffing per task | artifact content lines | Role, period, hours, hours rationale ("128 hrs/mo × 80% × 7 mo") |
| Requirement grounding | artifact citations → requirement → source quote | Walkable: any task's estimate → the requirement it satisfies → the verbatim PWS passage |
| Period structure | artifact content: period_structure section | The keeper table, read-only |

**Hard exclusions:** NO dollar figures — rates, costs, and totals are not this audience's question and not this token's scope. No commands of any kind. Nothing outside the artifact the token resolves to.

## Commands

None. The absence is the design: read-only that feels authoritative, not degraded (PRINCIPLES §8).

## States the screen must represent

1. **Valid token** → the document: provenance header, then structure. Print/PDF-friendly as a natural consequence of document-shaped layout (directors forward things)
2. **Revoked or expired token** → plain, non-alarming explanation; contact-the-sender guidance; no information leakage about the proposal
3. **Citation walk** → tap a task's grounding → requirement text → verbatim source quote with document + location. This is the trust interaction; it must be one gesture, not a navigation

## Explicitly not on this screen

Pricing of any kind. Editing of any kind. Navigation to any other proposal surface. Product chrome beyond minimal identity ("Generated by TrueBid" — this page is also quiet marketing to a senior stakeholder).
